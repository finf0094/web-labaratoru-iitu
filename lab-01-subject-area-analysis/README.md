## Что сказать на защите (кратко)

1. **Предметная область:** LLM-агенты, которые работают в цикле «рассуждение → вызов инструмента → наблюдение», подключают инструменты через MCP и отвечают по документам организации через RAG.
2. **Проблема:** нет открытой, независимой от вендора платформы с проверенной архитектурой, которая объединяет agent loop, MCP и RAG, безопасна (prompt injection) и поддерживает казахский и русский языки.
3. **Аналоги:** ISSAI KazLLM/Oylan, OpenAI, Microsoft Foundry, LangGraph, Dify.
4. **Критерии сравнения:** agent loop, MCP, встроенный RAG, наблюдаемость/оценка/guardrails, доступ/локальное развёртывание/казахский язык.
5. **Ограничения аналогов:** vendor lock-in и передача данных за рубеж, быстрые изменения функций, нет единой методики оценки качества, стоимости и безопасности, защита от prompt injection остаётся на разработчике.
