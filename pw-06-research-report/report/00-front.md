abstract: |
  This small-scale project evaluates three building blocks of the agentic AI platform designed in Practical Works 2–5: the retrieval step of retrieval-augmented generation (RAG), the exposure of the agent to poisoned retrieved content, and the overhead of exposing retrieval as a Model Context Protocol (MCP) tool. Using the open Kazakh question-answering dataset KazQAD (1 929 test questions, a 100 000-passage sub-corpus of Kazakh Wikipedia), five retrievers were compared. BM25 with prefix-5 truncation achieved the highest nDCG@10 (0.473), significantly above word-level BM25 (0.371), character n-grams (0.327), latent semantic analysis (0.032) and a hybrid reciprocal-rank-fusion run (0.459). Planted attacker passages reached the top-5 results in 96–100 % of cases for all lexical retrievers when they copied the question, and in 69–95 % when they copied half of it; a pattern-based guardrail detected all explicit injections in three languages but none of the paraphrased ones, with a 0.35 % false-alarm rate. Calling retrieval through MCP over stdio added a median of 3.0 ms per call. The results support morphology-aware retrieval as the default for Kazakh, show that retrieval itself offers no protection against injection, and confirm that MCP integration is cheap in latency terms. **Keywords:** retrieval-augmented generation, Kazakh language, BM25, prompt injection, Model Context Protocol, AI agents.
